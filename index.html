Evaluación anidada

P(x) = c₀ + (x − x₀)·( c₁ + (x − x₁)·( c₂ + … ) ). Se recorre de adentro hacia afuera y el resultado es b₀.
Motor de cálculo en Python — diferencias divididas y evaluación anidada 
def diferencias_divididas(X, Y):
    """Matriz triangular: T[i][j] = f[x_i, ..., x_{i+j}]"""
    n = len(X)
    T = [[0.0] * n for _ in range(n)]
    for i in range(n):
        T[i][0] = Y[i]
    for j in range(1, n):            # columna = orden de la diferencia
        for i in range(n - j):       # fila
            T[i][j] = (T[i+1][j-1] - T[i][j-1]) / (X[i+j] - X[i])
    return T

def evaluar_newton(coefs, X, x):
    """Multiplicación anidada: n productos y n sumas"""
    p = coefs[-1]
    for k in range(len(coefs) - 2, -1, -1):
        p = coefs[k] + (x - X[k]) * p
    return p

X = [1, 2, 4, 7]            # carga (x 100 req/s)
Y = [45, 65, 110, 220]      # latencia media (ms)
T = diferencias_divididas(X, Y)
print("P3(5) =", evaluar_newton(T[0], X, 5))   # 139.0 ms
